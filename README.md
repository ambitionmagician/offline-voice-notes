# Offline Voice Notes — record, transcribe on-device, search

A single-file installable PWA (index.html inline CSS/JS, manifest.json, sw.js) for voice notes: record audio with MediaRecorder, store notes in IndexedDB, transcribe on-device with the Web Speech API when available (graceful fallback: audio-only note), full-text search across transcripts, tags, rename, export all notes as a .zip-free single JSON or .txt bundle download, and share via the Web Share API. No server, no accounts, no external requests. The deliverable is the complete index.html, manifest.json, and sw.js source.
